## **요구 사항 분석과 기능 분해**

**1.개요**
1.1 목적
쇼핑몰 상품 리뷰를 수집·정제·분석해, 셀러(사용자)가 상품별 리뷰와 통계, 감성·키워드 인사이트를 대시보드로 확인하고 CS에 대응할 수 있게 한다.
1.2 사용자 정의
일반 사용자(셀러/운영자)

**2.기능 요구사항**
1.사용자는 회원 가입할 수 있어야 한다.
2.사용자는 로그인 할 수 있어야 한다.
3.사용자는 로그아웃 할 수 있어야 한다.
4.사용자는 회원 탈퇴 할 수 있어야 한다.
5.사용자는 상품별 리뷰를 조회햘 수 있어야 한다.
6.사용자는 리뷰에 CS답글을 작성할 수 있어야 한다.
7.사용자는 리뷰 통계(월별 추이 등)를 확인할 수 있어야 한다.
8.사용자는 리뷰 대시보드를 확인할 수 있어야 한다.
9.사용자는 불호리뷰를 대시보드 상단에 우선 노출해야 한다.
10.시스템은 리뷰 키워드 상위 10개를 제공해야 한다.
11.시스템은 리뷰 텍스트에서 특수문자 등을 제거하는 텍스트 클리닝을 수행해야 한다.
12.시스템은 긍정/부정 비율 통계를 제공해야 한다.
13.시스템은 경쟁사/타 상품과의 리뷰 분석을 제공할 수 있어야 한다.
14.쇼핑몰 바로가기

**3.MoSCoW 우선순위**
Must-1\~5,7,8
Should-6,9\~12
Could-13,14
Won't-15

필수 기능은 Must와 Should, 선택 기능은 Could

**4.프로젝트 범위 조정**
데이터 요구 사항
4.1 데이터 수집 및 구성
-쇼핑몰 리뷰 공개 데이터셋을 수집한다
-정형 데이터(리뷰 ID, 상품 ID, 평점, 작성일자, 옵션 등)와 비정형 데이터(리뷰 텍스트)를 정제한다.

4.2 데이터 전처리
-특수 문자 제거 및 텍스트 클리닝 파이프라인을 구축
-감성 분석 및 키워드 라벨링 파이프라인을 구축
-아래 테이블 간 관계를 설계하고 ERD를 작성
  *상품 정보
  *리뷰
  *감성 키워드 분석 결과
  *셀러 정보
  *위험 키워드 설정
-리뷰 텍스트와 상품 설명 문서의 임베딩을 저장한다.



# 요구사항 정의 및 기능 명세서: Pinpoint Review

## 1. 프로젝트 개요

- **프로젝트명:** Pinpoint (핀포인트 / Pinpoint Review)
- **목표 사용자:** 네이버 스마트 스토어, 쿠팡 등 중소형 셀러 및 브랜드 자사몰 마케팅/CS 담당자
- **핵심 가치:** 복잡한 리뷰 텍스트 속에서 긍/부정 핵심 키워드를 자동 추출하고, 단순 평점 이상의 비즈니스 인사이트(상품 문제 vs 유통/포장 문제 분리 등)를 대시보드로 제공하여 CS 대응 속도를 높이고 제품 개선 가이드를 도출.

## 2. 기능 분류 (Epic)

제시된 기능 요구사항을 기반으로 시스템 모듈을 7가지 핵심 에픽(Epic)으로 통합 분류했습니다.

| Epic | 분류명 | 포함 요구사항 | 우선순위 |
| --- | --- | --- | --- |
| **E1** | **계정 및 권한 관리** | FR-01~04 | Must |
| **E2** | **상품 및 리뷰 관리** | FR-05, 06 | Must |
| **E3** | **리뷰 답글(CS) 관리** | FR-13 | Should |
| **E4** | **데이터 수집·전처리·AI 파이프라인** | FR-11, 데이터 수집/전처리 요건 | Should (E5의 선행 조건) |
| **E5** | **통계 및 대시보드** | FR-07~10, 12 | Must / Should |
| **E6** | **선택 기능 (고도화)** | FR-14~16 | Could |
| **E7** | **공통·인프라** | 비기능 요구사항, 문서화 | 전 Epic 공통 |

## 4. 기능 누락 및 개선 확인 (Gap Analysis)

원문 기획 의도와 시스템의 실제 동작을 위해 보완해야 할 필수/권장 항목입니다.

| 구분 | 추가 및 보완 제안 사항 | 필요성 및 우선순위 |
| --- | --- | --- |
| **기능 보완** | **데이터 필터링 (기간/상품별)**

대시보드와 통계 화면에서 특정 기간(최근 1주/1개월) 및 상품별로 데이터를 조회하는 필터 기능. | **Must**

(통계 확인의 기본 전제) |
| **기능 보완** | **상품 목록·검색·상세 조회**

특정 상품의 리뷰를 조회하기 위해 사전에 진입해야 하는 상품 검색 및 목록 화면 추가. | **Must**

(리뷰 조회의 기본 전제) |
| **목적 교정** | **'CS 자동 챗봇' → 'LLM 맞춤형 답글 추천기'**

B2B 셀러 툴이므로 일반 고객용 챗봇이 아닌, 셀러가 부정 리뷰에 대응할 때 쓰는 사과문/가이드 자동 생성기로 변경. | **Should**

(기획 의도 부합) |
| **신규 제안** | **데이터 내보내기 (Export)**

주간/월간 보고서 작성을 위해 대시보드 통계 및 분석된 리뷰 데이터를 엑셀(CSV)로 다운로드하는 기능. | **Should**

(실무 활용도 대폭 상승) |
| **신규 제안** | **위험 키워드 설정 (CRUD)**

각 셀러가 자신의 제품군에 맞는 '위험 키워드(예: 이물질, 파손 등)'를 직접 등록하고 관리하는 기능. | **Should**

(불호 리뷰 상단 노출의 기준점) |
| **정책 확정** | **탈퇴 시 데이터 처리 정책**

작성한 리뷰나 CS 답글을 일괄 삭제할지, 작성자 정보만 익명화(Null 처리)할지 결정 필요. | **공통 정책** |
